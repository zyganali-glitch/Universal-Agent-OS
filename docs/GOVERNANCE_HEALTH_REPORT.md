# Governance Health Report

Future command:

`agent-os report --target .`

Purpose:
Generate a human-readable governance status report for a target repository.

Suggested output:
- active plan detected
- master roadmap detected
- latest evidence date
- gate summary
- NOT_RUN gates
- stale memory files
- docs sync status
- Tech-Debt Delta summary
- discovered work not yet planned
- recommended next action

Planned for a future release.
