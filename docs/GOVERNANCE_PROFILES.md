# Governance Profiles

Future CLI idea:

`agent-os init --profile light|standard|strict`

## light
For solo developers and small experiments.
- shorter Phase-0
- minimal gates
- required closure evidence

## standard
For serious personal projects and small teams.
- full Phase-0
- master roadmap
- child plans
- memory updates
- verify gates

## strict
For companies, agencies, regulated domains.
- full Phase-0
- formal evidence manifest
- PR template required
- CI verification required
- Tech-Debt Delta required
- explicit NOT_RUN handling

Status: Planned for a future release.
